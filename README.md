# Bidauc.in – Full Stack Online Auction Platform

Bidauc.in is a full-stack online auction web application that allows users to create auction listings, place bids, and manage products through an interactive dashboard.

## 🚀 Features

* User Authentication & Login System
* Auction Listing Management
* Real-Time Bidding Workflow
* Responsive Dashboard UI
* CRUD Operations
* MySQL / SQLite Database Integration
* Cloud Deployment using Render
* Version Control with Git & GitHub

## ⚙️ Installation & Setup

### 1️⃣ Clone Repository

```bash
git clone https://github.com/Acash16/Bidauc.in.git
```

### 2️⃣ Navigate to Project Folder

```bash
cd Bidauc.in
```

### 3️⃣ Create Virtual Environment

```bash
python -m venv venv
```

### 4️⃣ Activate Virtual Environment

#### Windows

```bash
venv\Scripts\activate
```

#### Mac/Linux

```bash
source venv/bin/activate
```

### 5️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

### 6️⃣ Run Flask Application

```bash
python app.py
```
